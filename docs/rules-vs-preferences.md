# Rules and preferences

**Rules** protect correctness, legality and uploadability. They live in this repository, and no preference
overrides them:
- the Alembic package contract, checked against its newest version at pack;
- valid orz syntax and notations;
- copyright and provenance;
- scientific accuracy;
- the accessibility floor;
- the 3C control core. The gate blocks on defects and obligations, never on questions.

**Preferences** are the instructor's taste. They live in `~/.coursewerk/` (`preferences.md`, `styles.md`,
`templates/`, `skills/`), so Coursewerk updates never touch them. Examples:
- how a study guide or a deck is structured;
- how detailed explanations go;
- which tools draw the graphics;
- which theme to use.

Read them first and apply them; what the instructor says this session comes before them. No check reads them, so
they shape the materials and never the 3C results.

**Frames are clothes.** The orz frames and Alembic are updated from time to time. Their notations stay stable while
the assembled look improves, so always assemble with the newest. The gate blocks only on grammar that cannot
render. A theme, template, layout or other name the installed frame doesn't know is a note, because a newer frame
may have it. Nothing limits what an agent may use.
