# Coursewerk — agent entry (Gemini)

Coursewerk's entry instructions are in **[`CLAUDE.md`](CLAUDE.md)**. They are provider-neutral and apply to any AI
agent. **Read `CLAUDE.md` first, then `PROCEDURE.md`.** This file exists so that Gemini CLI, which reads
`GEMINI.md`, reaches the same instructions. `AGENTS.md` has a short orientation.

Before writing a deliverable, fetch the newest orz skills: `node scripts/skills.mjs --into <your skills folder>`, or
read `https://cdn.jsdelivr.net/npm/<pkg>/<pkg>-skills/SKILL.md` for orz-markdown, orz-mdhtml, orz-slides and orz-paged.
Never use a copy you cannot show is the newest.
